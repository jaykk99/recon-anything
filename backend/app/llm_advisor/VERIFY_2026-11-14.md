## Chain behaviour proven live

- Winner-first ordering works: meromero answered the ranking call.
- Fallback works: when meromero failed (transport, 2.8s), heretic
  answered the same call 8.3s later with a good result.
- Total worst case observed for a 4-call enrichment: ~51s. A full
  chain walk with Horde timeouts can take minutes; the local Dolphin
  fallback sits after the Bro gateway so a dead chain fails over to
  the gateway instead of burning ~10 min on local inference.

## Known limits (honest)

- Detector drafting is the weak task for every model tested: all
  returned detectors miss `_mint(to, amount)`. `draft_detector`
  compile-checks, but callers must functionally test the code before
  using it as a plugin.
- Horde transport flakiness is real (~40% per-attempt failure today);
  the chain exists because of it, not in spite of it.
